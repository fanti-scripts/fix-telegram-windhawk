# Fix Telegram — утилита для Windows

Чинит Telegram Desktop, когда после установки Windhawk (или вообще после
любых изменений в системе) текст отображается «штрихами» вместо букв.

Ни один модуль Windhawk не удаляет и не отключает — только исключает из них
процесс Telegram.

---

## Как запустить

Двойной клик по **`Run-Fix.cmd`** → подтверди запрос прав администратора (UAC) →
в окне появится отчёт и Telegram перезапустится.

Посмотреть состояние ничего не меняя: двойной клик по **`Run-Diagnose.cmd`**.

---

## Что именно делает утилита

| Шаг | Действие |
|-----|----------|
| 1 | Резервная копия ветки реестра Windhawk (`*.reg`) в папку `WindhawkFix-backup-<дата>` |
| 2 | Добавляет `Telegram.exe` в список исключений модулей с `Include = *` |
| 3 | Сбрасывает кэш растеризации шрифтов (`FontCache`, `FNTCACHE.DAT`) — **это и была главная причина** |
| 4 | Перезапускает службу Windhawk |
| 5 | Перезапускает Telegram |

Шаг 2 универсален: он срабатывает на **любой** Windhawk-модуль, который
работает во всех процессах, независимо от версии и от того, какие модули
ты поставишь после переустановки. Модули с конкретным списком процессов
(например, только `explorer.exe`) не трогаются — они в Telegram и так не
попадают.

---

## Ключи командной строки

```powershell
# починить (по умолчанию)
.\Fix-Telegram-Windhawk.ps1

# только отчёт, ничего не менять
.\Fix-Telegram-Windhawk.ps1 -Diagnose

# починить, но не трогать кэш шрифтов
.\Fix-Telegram-Windhawk.ps1 -SkipFontCache

# починить и не перезапускать Telegram
.\Fix-Telegram-Windhawk.ps1 -KeepTelegramRunning

# без ожидания Enter (для автотестов и скриптов)
.\Fix-Telegram-Windhawk.ps1 -NonInteractive
```

Скрипт сам поднимет права до администратора, если запущен не из-под админа.

---

## Порядок после переустановки Windows

1. Поставь Windhawk.
2. Поставь нужные модули и включи их.
3. Поставь Telegram Desktop и запусти.
4. Запусти `Run-Fix.cmd`.

---

## Если проблема вернулась

Симптом: буквы превращаются в вертикальные штрихи в пару пикселей, а узкие
символы вроде `()` и `!!` иногда рисуются нормально. Это битый кэш шрифтов.
Просто запусти `Run-Fix.cmd` ещё раз — он идемпотентный, повторный запуск
ничего не сломает и не будет дублировать записи в списках исключений.

Дополнительно: иногда помогает перезагрузка Windows — она пересоздаёт кэш
шрифтов сама.

---

## Откат

Файл `.reg` из папки `WindhawkFix-backup-<дата>` можно применить двойным
кликом (потребуются права администратора). Чтобы откатить и исключения
Telegram — открой Windhawk, шестерёнка у модуля → Process exclusion →
убери `Telegram.exe`.
